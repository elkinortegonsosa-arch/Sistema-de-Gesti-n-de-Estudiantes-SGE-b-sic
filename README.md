# Sistema-de-Gesti-n-de-Estudiantes-SGE-b-sic
Una institución educativa necesita consultar información básica de sus estudiantes sin depender de una hoja de cálculo o de búsquedas manuales. Para resolver este caso se plantea un Sistema de Gestión de Estudiantes (SGE) que funciona por consola y permite registrar personas, ver los datos guardados y buscar un registro a partir de su identificador
